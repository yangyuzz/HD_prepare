검수·개선 사항
- 기존 실습 12문항에 없던 GROUP BY·HAVING·DISTINCT·NULLIF·OFFSET 등의 직접 실행 문제 추가
- PostgreSQL 4장 내 모든 핵심 개념을 실습으로 확인할 수 있도록 확대
- 5장에서 배우는 CAST·ROUND를 4장 과제의 필수 풀이에서 제외
- 샘플 스키마와 컬럼명(commission_pct 등) 일치 확인
- 의도적으로 결과가 0건/NULL인 예제는 해설에서 차이 설명
- 학습 범위 바깥의 JOIN, 서브쿼리, DATE_TRUNC 등의 선행 문법 사용하지 않음
- 각 SQL을 hd_sample_data.sql의 동일한 데이터 행을 적재한 로컬 검증 환경에서 확인함
  (PostgreSQL 전용 ILIKE / DATE·TIMESTAMP 리터럴은 검증 시 동등 구문으로 변환했으며
   실제 PostgreSQL 서버에서의 일괄 실행까지 보증하는 것은 아님.)
